CAMPUSCUE WEBSITE PROJECT

Open index.html in a modern browser. No installation is needed.

Files:
- index.html: responsive interactive website prototype
- Project_Notes.txt: problem, target users, solution, features, limitations, improvements, success metric
- Instagram_Post_Simple.svg: simple promotional Instagram post
- Instagram_Post_Creative.svg: more engaging promotional Instagram post
- Instagram_Post_Before_After.svg: comparison post showing scattered task management versus an organised dashboard

The poster SVGs use a 1080 x 1350 (4:5) Instagram portrait canvas. Open them in a browser or import into a graphics editor/Canva workflow that supports SVG.

Demo: Open index.html, click “Try demo tasks”, add a task, search/filter, mark it complete, delete it, and refresh to demonstrate browser-local persistence.

Limitations: Tasks stay in the current browser. There are no accounts, shared cloud storage, notifications, or AI integration in this prototype.
